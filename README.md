# C++ Command Prompt

A custom command-line application developed in C++ as part of an Object-Oriented Programming project.

The project recreates some of the functionality of a basic command prompt, allowing users to execute commands for working with files, directories, text, and the command prompt.

## Features

The application supports commands including:

* `time` — displays the current time
* `date` — displays the current date
* `echo` — prints text to the console
* `touch` — creates a file
* `wc` — displays information about a file
* `head` — displays the first lines of a file
* `truncate` — changes the size of a file
* `rm` — removes a file
* `prompt` — changes the command prompt
* `batch` — executes commands from a batch file
* `tr` — performs text transformation

The project also includes command arguments and file handling functionality.

## Getting Started

### Requirements

* Windows
* Visual Studio with C++ development tools

### Running the Project

1. Clone the repository:

```bash
git clone https://github.com/milemacesic/command_prompt_cpp.git
```

2. Open the solution file in Visual Studio:

```text
OOP1Projekat-mm220721.slnx
```

3. Build the solution.

4. Run the application.

The program will open a custom command prompt where the supported commands can be entered.
